# Guide des présentateurs — histoires et quiz

1. Créer une salle via Espace présentateur, puis projeter le QR code. La salle expire quatre heures après création.
2. Attendre la classe dans le lobby. Cliquer Commencer ou appuyer sur →.
3. Pour chaque entreprise : laisser deviner à partir du teaser ; → raconte l’histoire anonyme ; → révèle le nom, la photo et la forme.
4. Chaque pause contient trois quiz de 20 secondes. Les téléphones enregistrent le choix au toucher, sans justification.
5. Après chaque correction, → affiche le classement, puis → poursuit. ← revient à l’explication.
6. Rappel final : deux minutes, huit formes. Brouillons automatiques ; Valider mes réponses fige la réponse et le temps de score. Sans validation, le dernier brouillon compte à la fermeture. Une clôture manuelle utilise l’heure de clôture pour les brouillons.
7. Jusqu’à 8 000 points au rappel, au prorata des formes correctes et sans doublons. Toutes les formes correctes à la fin : 4 000 points. Les participants validés attendent la révélation collective.
8. Dernière diapositive : cliquer Lire la vidéo. Le son est activé ; les commandes du lecteur restent utilisables au clavier. Quitter la diapositive arrête la lecture.

Pas d’affectation P1/P2/P3 ni de durée totale imposée.

## Raccourcis

- ← / →, PageUp / PageDown : navigation ; Espace avance sauf dans un contrôle.
- F : plein écran. P : pause du chronomètre général, pas des délais des questions.
- R : resynchroniser. ? : aide. Échap : fermer une fenêtre.
- Fermer une question dans ses dix premières secondes exige une seconde flèche droite.
- Les raccourcis de présentation n’interceptent pas les commandes du lecteur vidéo.

Les notes s’affichent sur le projecteur tant que leur fenêtre est ouverte. Pendant le rappel, les menus donnant des indices restent masqués. Une salle expirée ne peut pas reprendre : créer une nouvelle salle.
